GMAIL SYNC

Connect your inbox

This version connects directly from your browser to Gmail using Google's official OAuth flow. We never ask for your Gmail password or permission to send or delete email.

One-time Google setup required
  1. Open Google Cloud Console, create a project, and enable the Gmail API.
  2. Configure the OAuth consent screen for personal use, with the gmail.readonly scope. Add yourself as a test user if required.
  3. Create a Web application OAuth client, and authorize the JavaScript origin where this app runs (e.g. http://localhost:8000).
  4. Paste the client ID above, save, then click Connect & sync.

Google may require verification/security assessment for wider public distribution of apps using restricted Gmail scopes. For a personal test app, use a test-user configuration.
