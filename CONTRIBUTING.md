# Contributing and extending

The portfolio is intended as a personal code sample. Open an issue before major changes. New demo rules should include synthetic sample inputs, an explicit reference to applicable vendor/NIST documentation, a false-positive/limitation statement, and a repeatable automated test.

Run `npm run check:js && npm run verify` before submitting proposed changes. Do not attach screenshots or excerpts of customer systems, credentials, PHI, CUI or restricted employment materials.

No open-source license has been selected. Contact the owner before redistributing or reusing the source code outside the repository.
