# Architecture illustrated posters

These are eight original AI-generated illustrative posters from the same ChatGPT conversation, optimized to WebP format for GitHub Pages.

Upload these eight .webp files together to the public repository folder `architectures/posters/` to enable the **Illustrated Poster** view of each reference architecture. The gallery automatically displays interactive SVG fallbacks until each file exists.

Files are educational and require human review for accuracy, particularly authorization boundaries, product eligibility, evidence scope and regulatory requirements. They do not demonstrate certification.
